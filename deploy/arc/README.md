# deploy/arc — архивы и дампы

Каталог для файлов, которые оператор создаёт **на сервере** во время обслуживания:

- дампы PostgreSQL перед обновлением с миграциями и перед откатом схемы
  (`DEPLOYMENT.md` §9.5, §10, §12);
- любые разовые выгрузки, которые нужно на время положить рядом с проектом.

## Почему каталог есть в репозитории, а его содержимое — нет

Каталог **отслеживается** (этим файлом), поэтому существует сразу после `git clone` и
перенаправление `> deploy/arc/nexus_….sql` не падает с `No such file or directory`.

Содержимое **игнорируется** — `.gitignore` (`/deploy/arc/*` с исключением для этого README) и
`.dockerignore` (`deploy/arc/`). Два следствия, ради которых так сделано:

1. дамп не появляется в `git status` и не выглядит как незакоммиченная правка;
2. дамп не попадает в контекст сборки образов (builder-стейдж копирует дерево целиком) —
   иначе выгрузка боевой БД осела бы в слое образа.

## Обслуживание

Каталог не чистится автоматически. Дампы занимают место, поэтому старые удаляйте сами:

```bash
find deploy/arc -name '*.sql' -mtime +30 -delete
```
