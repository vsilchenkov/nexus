DataBus adminPhase 3 backend

Backend полностью готов. Полноценный React SPA — на этапе Phase 3 frontend (см. roadmap). Пока используйте REST API напрямую.

Быстрый старт

  1. docker compose -f deploy/docker-compose.yml up -d
  2. make set-admin-password PASSWORD=...
  3. Логин через POST /api/auth/login ниже.

API

Аутентификация

POST /api/auth/login    { "login": "admin", "password": "..." }
POST /api/auth/logout
GET  /api/auth/me

Узлы

GET    /api/nodes
POST   /api/nodes        (admin)
GET    /api/nodes/:id
PUT    /api/nodes/:id    (admin)
DELETE /api/nodes/:id    (admin)

Пользователи (admin)

GET    /api/users
POST   /api/users
PUT    /api/users/:id
DELETE /api/users/:id
POST   /api/users/:id/password

API-токены

GET    /api/tokens
POST   /api/tokens       { "name": "...", "scopes": ["nodes:read","logs:read"] }
POST   /api/tokens/:id/revoke
DELETE /api/tokens/:id

Audit log (admin)

GET    /api/audit?actions=node.create,node.update&limit=50

Что доступно прямо сейчас

  • Sync POST /v1/request/{path} и async /v1/requestAsync/{path} на Receiver (порт 8080).
  • gRPC SenderService на :9090 (Sender admin HTTP — :9091).
  • Логи запросов в ClickHouse-таблице vika_logs.<table> узла.
  • Метрики Prometheus на каждом сервисе /metrics.

Полноценный SPA (React + TanStack Query + shadcn/ui + i18n) появится одновременно с собранным /web-ui/dist/. См. web-ui/README.md для инструкций по разработке UI.
