Структура карточки

  • Цветной акцент слева — статус узла: OK зелёный, Очередь/Медленно жёлтый, Down красный, Пауза синий, Отключён серый.
  • Шапка — имя узла (моноширинный, обрезается с многоточием при переполнении), chip с методом (request / requestAsync), pill со статусом, меню «⋮» справа.
  • Метрики — три ключевых значения: вход за час, p95 latency (или Kafka lag для async-узлов / накопленные сообщения для paused), число ошибок. Цвет значения красный/жёлтый при превышении порогов.
  • Спарклайн — мини-график трафика за последний час, 12 столбиков (5-минутные интервалы). Цвет соответствует статусу. Для отключённых — пустой/блёклый.
  • Подвал — target URL (или {url_base из запроса} для динамического режима) и время последнего обновления.
  • Клик по карточке — переход на detail-страницу узла (см. §7.4). Меню «⋮» — действия без перехода (включить / выключить / редактировать / удалить).

Раскладка

  • Сетка 3 колонки на desktop (≥1024px), 2 на tablet (768–1023px), 1 на mobile.
  • Сортировка по умолчанию — узлы с проблемами первыми (err → warn → paused → ok → disabled), внутри статуса по убыванию трафика.
  • Live-обновление через SSE или polling 5–10 сек (см. §7.12). Изменения значений показываются с короткой подсветкой фона.
