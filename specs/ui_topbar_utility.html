§7.12

Утилитарная зона глобальной шапки

Правая часть глобального topbar, видимая на всех страницах Nexus. Содержит: Swagger (документация API), Язык (быстрое переключение EN/RU), Тема (светлая/тёмная/системная), Аватар пользователя (профиль, смена пароля, выход). Зона отделена от основной навигации, потому что эти действия не относятся к рабочему процессу, но должны быть в один клик откуда угодно.

1

Шапка как она выглядит на любой странице. Слева — бренд и хлебные крошки текущего экрана; справа — утилитарные иконки и аватар.

Клик на Swagger · выбор API

Клик открывает компактный popover со списком: документация Receiver API (внешний контракт для клиентов) и Web Service API (контракт админки и API-токенов). Обе ведут на /swagger/... того же процесса (см. §11, единый Go-бинарь раздаёт и UI, и Swagger через embed.FS). Открытие — в новой вкладке.

Поведение Swagger

  • Web Service раздаёт документацию по /swagger/receiver/ (Receiver API, внешний контракт /v1/*) и /swagger/web/ (Web Service API, контракт админки). Оба файла собираются make swagger и встраиваются в Go-бинарь через embed.FS.
  • Клик по иконке — короткий popover из двух пунктов. Клик по пункту — window.open(url, '_blank'), документация открывается в новой вкладке.
  • Иконка ↗ в углу кнопки заранее предупреждает пользователя, что переход внешний и не покинет основной поток работы.
  • Если в проекте останется только один Swagger (что вероятно, поскольку Receiver и Web Service — это два разных бинаря в разных доменах) — popover опускается и иконка превращается в простую ссылку.

Поведение остальных пунктов

  • Язык. Применение мгновенное, без перезагрузки. Сохраняется в users.lang (PostgreSQL) и в Redis-сессии — см. §7.11. Серверные ответы API учитывают Accept-Language.
  • Тема. Сохраняется в localStorage. «Системная» подписывается на matchMedia('(prefers-color-scheme: dark)'). Все экраны переключаются без перезагрузки через CSS-переменные.
  • Аватар. Цвет — детерминированный градиент из логина (одинаковый между сессиями). Пункт «Audit log» виден только админам (v-if="user.role === 'admin'"); для viewer строка не отображается.

Раскладка

  • Порядок справа налево: аватар · разделитель · Тема · Язык · Swagger · spacer.
  • Расстояние между иконками — 4px, размер кнопки 34×34px, радиус скругления --radius-md (7px).
  • На мобильных (< 768px) Swagger и Язык сворачиваются под одну иконку «⋯», тема и аватар остаются как есть.
  • Все dropdown'ы закрываются по клику вне, по Esc, по выбору пункта. Никаких backdrop-overlay'ов — обычные popover'ы.

Что Claude Code должен учесть

  • Использовать DropdownMenu / Popover из shadcn/ui — не писать свой dropdown с нуля.
  • Tooltip из shadcn (TooltipProvider) с задержкой 400–500 мс. Без задержки tooltip раздражает.
  • Доступность: aria-label для каждой иконки, aria-expanded на кнопке popover, role="menu" на dropdown.
  • Все четыре дропдауна — глобальные компоненты, монтируются один раз в AppShell. Не дублируются на каждой странице.
