Nexus — UI эталон

Визуальный референс всех согласованных экранов и форм. Передаётся в Claude Code как эталон для реализации фронтенда (React + TypeScript + Vite + TanStack Query + shadcn/ui + Tailwind, см. §17 ТЗ).

Каждый экран помечен ссылкой на раздел ТЗ (§7.x), где описано поведение, валидация, состояния и API-эндпоинты. Этот документ фиксирует внешний вид и компоновку; логика — в ТЗ.

Как использовать. Дизайн-токены вверху <style> (цвета, радиусы, шрифты, отступы) — единый источник правды. При реализации перенести их в Tailwind-config / CSS-переменные один в один. Все экраны в тёмной теме; светлая строится зеркально от тех же токенов. Иконки — Tabler Icons (в проде — lucide-react, имена совпадают почти везде).

§7.5

Удаление узла — диалог

Чекбокс «Также удалить таблицу логов» (выключен по умолчанию). Для активации кнопки требуется ввести path узла. По умолчанию таблица остаётся «осиротевшей».

Удалить узел webhook/send?

За всё время обработано 1,284,002 запросов. Логи — в таблице vika_logs.webhook_send.
Таблица останется в ClickHouse — удалить позже можно из Settings → ClickHouse → Осиротевшие.

§7.11

Settings → Language

Выбор языка для текущего пользователя. English (по умолчанию) / Русский. Карточки с флагами. Логи и метрики всегда на английском.

Язык интерфейса
Применяется только к текущему пользователю. Изменение вступает в силу сразу.
Числа и даты форматируются по локали. Логи в ClickHouse и метрики Prometheus — всегда на английском.
