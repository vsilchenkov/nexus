§99

Группировка узлов

Общий для инсталляции справочник групп и группировка списка узлов по ним — в обеих раскладках. Узлы без группы идут первыми и без заголовка, как сегодня; ниже — секции по группам в порядке поля «Порядок». Существующая сортировка («проблемные первыми, внутри статуса — по трафику») не меняется, она начинает действовать внутри каждой секции. Полный текст — sections/99-node-groups.md.

99.5

Экран «Узлы» — раскладка «Таблица»

Одна таблица с общей шапкой: секция группы — отдельный tbody, заголовок — строка на всю ширину. Внутри «1С Обмен» первым стоит erp/orders со статусом Degraded: правило «проблемные наверх» работает в пределах группы, а не всего списка.

99.8

Настройки → «Группы» (роль manager)

Таблица справочника с порядком и стрелками, счётчиком узлов и действиями. Удаление заблокировано, пока к группе привязаны узлы: подсказка на кнопке, 409 на сервере и ON DELETE RESTRICT в СУБД — три уровня одной защиты.

99.8

Диалог группы

Один компонент на создание и правку. Имя — свободный текст 1…100 после обрезки пробелов (не RFC-token, как у заголовков: группы называет человек). Переименование используемой группы разрешено — узлы ссылаются по id.
