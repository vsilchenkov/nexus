Lag-график · с разбивкой по партициям

Для consumer lag важно знать не только общую сумму, но и распределение по партициям — если одна партиция накопила весь lag, проблема в её consumer'е, а не в общем темпе. Поэтому в тултипе мини-bar чарт по партициям.

Маркер ошибки · отдельное состояние

Если на графике есть точечные событий (например, всплеск ошибок, deploy-маркер), при наведении на сам маркер тултип показывает что случилось, а не просто «значение в момент времени». С ссылкой-действием внутри.

Иерархия информации в тултипе

  • Сверху — контекст времени: точка или интервал (15:43 → 16:13), плюс длительность отдельным шрифтом меньше (30 мин).
  • Под ним — главное значение крупным шрифтом (24 px, font-mono, bold). Это то, что глаз ловит первым.
  • Дальше — детализация серий или категорий: цветной маркер слева, имя серии, значение справа. Отсортировано по убыванию.
  • Подвал — короткий вывод или дельта: «пик за период», «consumed < produced ▼ −294/с», «всплеск ошибок». Один признак, не два — иначе теряется фокус.
  • Опционально — кнопка-действие со ссылкой: «Открыть логи», «Перейти к узлу».

Визуальные правила

  • Полупрозрачный фон rgba(22, 25, 31, 0.96) + backdrop-filter: blur(8px) — чтобы тултип не «врезался» в график как кирпич.
  • Тонкая граница 0.5px solid var(--border-strong) + двойная тень: близкая для глубины, дальняя мягкая.
  • Маленькая стрелка-указатель (::before) к точке курсора. Направление зависит от позиции тултипа: down / up / left / right.
  • Маркеры серий — квадратики 8×8 для bar-серий, тонкие линии 10×2 для line-серий, пунктир для dashed-серий. Точно соответствуют стилю серии на самом графике — это главное, иначе пользователь путается.
  • Шрифт: подписи серий — font-sans, значения — font-mono. Так числа выравниваются по разрядам, читать легче.
  • Цвет «главного значения» меняется в зависимости от категории: обычное — --text-primary, warn — оранжевое, error — красное. Не используем зелёный для главного значения — он используется для дельт.

Позиционирование (Floating UI / Popper)

  • По умолчанию — над курсором (placement="top"), смещение 12 px.
  • Если до верха края недостаточно — авто-флип вниз. Если до правого края — флип влево. Стрелка автоматически выравнивается на точку курсора.
  • Тултип не следует за курсором посимвольно — он привязан к ближайшей точке данных (snap). Это устраняет «дрожь» при медленном движении.
  • Появление с задержкой 150 ms (не сразу), исчезновение мгновенно. Это убирает мерцание при быстром проходе курсора по нескольким столбикам.

Что Claude Code должен использовать

  • Recharts <Tooltip content={...} /> или Visx tooltip — обе библиотеки позволяют рендерить произвольный React-компонент. Не использовать дефолтные тултипы — они не дают такой типографики.
  • Один компонент <ChartTooltip /> с пропсами { period, primary, series, footer, action }. Переиспользовать на всех графиках Nexus.
  • Для позиционирования — @floating-ui/react (бывший Popper.js). Поддерживает auto-flip, shift, arrow из коробки.
  • Snap к ближайшей точке: useTooltipInPortal из visx или activeIndex в recharts.
