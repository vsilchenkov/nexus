§7.5 + §7.15

Выбор заголовков из справочника

Combobox с автодополнением для секции «Проброс заголовков» формы узла. Подсказки — из общей справочной таблицы headers_catalog. Новые заголовки, не найденные в каталоге, создаются автоматически прямо из дропдауна без отдельной формы и сразу попадают в выбранные.

Пользователь начал печатать x-r. Дропдаун показывает совпадения по prefix-match, отсортированные по usage_count desc. Уже выбранные элементы помечены «использован», клик по ним ничего не делает.

3

Состояние · недопустимое имя

Пользователь ввёл X My Header с пробелом — это нарушает RFC 7230 (имя HTTP-заголовка не может содержать пробелов). Кнопка «Создать» disabled, рядом — причина. Реальная проверка по regex ^[a-zA-Z0-9!#$%&'*+.^_`|~-]+$.

Поведение и контракты

  • Источник данных. Таблица headers_catalog в PostgreSQL (см. §5.1). Каталог общий для всей инсталляции — заголовок, добавленный одним админом, виден всем.
  • API. GET /api/headers?q=<prefix>&limit=20 — поиск, возвращает {id, name, description, usage_count}. POST /api/headers с {name, description?} — создаёт запись (автоматически из combobox), возвращает созданную запись. Создание идемпотентное по case-insensitive имени: повторный POST с тем же именем вернёт существующую запись с 200, а не ошибку.
  • Кеш на клиенте. TanStack Query, queryKey ['headers', q], staleTime 30 сек. После успешного POST — invalidate всех queries по префиксу ['headers'], чтобы новый заголовок появился во всех открытых формах.
  • Дебаунс ввода — 150 мс. Без дебаунса каждое нажатие клавиши шлёт запрос; с дебаунсом UI остаётся отзывчивым, нагрузка на backend минимальная.

Клавиатура

  • ↑ ↓ — навигация по списку.
  • Enter — выбрать подсвеченный элемент. Если ничего не подсвечено, но в поле есть валидный текст без совпадений — сработает «Создать».
  • Esc — закрыть дропдаун, очистить поле.
  • Tab — перейти к следующему полю формы (combobox закрывается).
  • Backspace в пустом поле — удалить последний chip.

Валидация имени

  • Regex: ^[a-zA-Z0-9!#$%&'*+.^_`|~-]+$, длина 1–100 (по RFC 7230).
  • Проверка на клиенте перед показом «Создать»; ту же валидацию backend выполняет в POST /api/headers, чтобы нельзя было обойти UI.
  • Имя сохраняется в каталог в том виде, в котором ввёл пользователь (включая регистр и оригинальный case дефисов), без нормализации. Поиск — case-insensitive.

Что Claude Code должен учесть

  • Использовать готовый combobox-компонент из shadcn/ui (Command из cmdk) или Radix UI — не писать свой с нуля.
  • Список выбранных хранится в react-hook-form как string[] (имена заголовков), а не id[] — это упрощает сериализацию узла в JSON для API и не привязывает форму узла к ID каталога.
  • При сохранении узла backend разрешает имена в ID каталога (name → id), записывает в node_headers. Если какое-то имя в каталоге исчезло между моментом открытия формы и сохранением — backend создаёт его автоматически. То есть гонок «фронт прислал имя, которого больше нет» быть не может.
  • Доступность: role="combobox", aria-expanded, aria-activedescendant, aria-controls. Это уже встроено в Radix/cmdk, своё не пишем.
