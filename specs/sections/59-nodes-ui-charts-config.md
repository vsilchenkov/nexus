# 59. Мини-графики в списке узлов, перенос узла из формы, конфиг узла и копирование URL лога

Раздел — набор UX-доработок существующих экранов (frontend-only, серверных изменений нет):
мини-график трафика в табличном представлении списка узлов, переезд кнопки «Перенести» в форму
правки узла, расширение read-only вкладки «Конфиг узла» и копирование полного URL из журнала
запросов. Развивает §22 (карточки Overview), §18 (перенос узла между командами), §21 (вкладки узла),
§44/§47 (логи и спарклайны).

Карта реализации — [../IMPLEMENTATION.md](../IMPLEMENTATION.md).

## 59.1 Мини-график трафика в таблице узлов

Таблица (`overview.view.table`) показывала те же метрики, что карточки, но без спарклайна — оценить
форму трафика можно было только переключившись в карточки.

- Последняя колонка таблицы (ранее — кнопка «Перенести», см. §59.2) отдана мини-графику.
- Компонент и данные — **те же, что в карточках**: `Sparkline` на массиве `spark` из
  `GET /api/metrics/nodes`, который список узлов уже запрашивает. Новых запросов и новых полей
  API не появляется.
- Функционал идентичен карточному: тултип по столбцу (окно бакета + число запросов) и клик по
  столбцу → логи узла за окно этого бакета (§47.4), только для узлов с таблицей логов.
- Колонка фиксированной ширины: столбцы спарклайна растягиваются (`flex-1`), без фиксации график
  съедал бы остаток строки. Переполнение уходит в горизонтальный скролл обёртки.
- Заголовок колонки — ключ `overview.table.traffic`.

## 59.2 Кнопка «Перенести» — в форме правки узла

Перенос узла в другую команду вызывался из списка узлов (кнопка в строке таблицы и в карточке).

- Кнопка убрана **из обоих представлений** списка.
- Новое место — ряд действий формы правки узла, между «Отмена» и «Поделиться».
- Условия показа прежние: только существующий узел (у нового нет `id`) и роль **admin** —
  эндпоинт `POST /api/nodes/{id}/move` admin-only, у остальных клик упёрся бы в 403.
- Диалог выбора целевой команды переиспользуется без изменений логики (`GET /api/teams` →
  `POST /api/nodes/{id}/move`), вынесен в отдельный компонент.
- **После успешного переноса пользователь уводится на список узлов**: узел оказался в другой
  команде, текущая форма правки для него стала чужой и сервер вернул бы 404 (team-scope).

## 59.3 Чтение логов не должно продолжаться после закрытия

Требование: при закрытии консоли логов или переходе на другую страницу логи не должны читаться,
чтобы не создавать лишнюю нагрузку.

Проверено — поведение уже корректное, изменения кода не потребовались:

- Опрос через `refetchInterval` react-query привязан к живым наблюдателям запроса; параметр
  `refetchIntervalInBackground` в проекте не используется нигде.
- Страница `/logs` — обычный роут, при навигации размонтируется; вкладка логов узла рендерится
  условно (`tab === "logs"`), при переключении вкладки размонтируется.
- Live-режим вкладки логов работает через `EventSource`, поток явно закрывается в cleanup эффекта.
- Дополнительные ограничители остаются в силе: опрос снапшота идёт только когда список
  прокручен вверх, в live-режиме снапшот-запрос выключен.

## 59.4 Команда узла на вкладке «Конфиг узла»

Read-only сводка настроек узла не показывала, какой команде узел принадлежит.

- Добавлена строка «Команда».
- Эндпоинт узла отдаёт только `team_id` (UUID) — имени команды в ответе нет. Имя резолвится по
  членствам пользователя (`GET /api/me/teams`); запрос общий с шапкой, react-query дедуплицирует его
  по ключу, лишнего обращения к API не возникает.
- Если членство не найдено (например, админ смотрит узел команды, в которой не состоит) —
  показывается сам идентификатор команды.

## 59.5 Передаваемые заголовки на вкладке «Конфиг узла»

- Добавлена строка «Проброс заголовков» — список `forward_headers` чипами, в том же виде, что и в
  редакторе формы.
- Пустой список отображается как «—». Смысловая сноска: пустой список означает, что наружу уходит
  только `Content-Type` (он пробрасывается всегда).

## 59.6 Копирование полного URL записи журнала

В таблице логов узла колонка URL обрезается по ширине, а полный адрес был доступен только в нативной
браузерной подсказке — оттуда его нельзя скопировать.

- Ячейка URL обёрнута в подсказку UI-кита (Radix): в ней полный адрес с переносом и кнопка
  «Скопировать».
- Подсказка наводимая — курсор можно завести внутрь и нажать кнопку; таблица в обычном состоянии
  не меняется (кнопка редкая, навязчивый элемент в каждой строке не нужен).
- **Неочевидность:** подсказка рендерится в портал, но React-события всплывают по React-дереву —
  без остановки всплытия клик по кнопке копирования дошёл бы до обработчика строки и
  свернул/раскрыл запись. Всплытие гасится в контейнере содержимого подсказки.

## 59.7 Вне scope

- Серверных изменений нет: `team_id` и `forward_headers` уже присутствовали в ответе API, метрики
  спарклайна — в существующем `/api/metrics/nodes`.
- Перенос узла между командами по существу не менялся — только точка входа в UI.
