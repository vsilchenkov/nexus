# 65. Команда узла на форме и представление команды «только имя»

Раздел выводит принадлежность узла команде на форме создания/редактирования узла и унифицирует
**представление команды** в интерфейсе узла: везде показывается только человекочитаемое имя команды
(без slug и без UUID). Развивает §18 (multi-tenancy), §21 (вкладка «Конфиг»), §58 (резолвер команды
узла), §59 (команда во вкладке «Конфиг»).

Карта реализации — [../IMPLEMENTATION.md](../IMPLEMENTATION.md) (§4.45).

## 65.1 Проблема

Форма узла ([NodeSettings.tsx](../../web-ui/src/pages/NodeSettings.tsx)) нигде не показывала, к какой
команде принадлежит редактируемый (или создаваемый) узел — при работе в нескольких командах оператор
не видел контекста без взгляда в шапку. Вкладка «Конфиг» команду показывала (§59), но в формате
«Имя (slug)» с фолбэком на сырой UUID — технические идентификаторы в read-only-инфо не нужны.

## 65.2 UI

- **Форма узла** — read-only строка `Команда: <имя>` вверху правой колонки (сайдбар), над карточкой
  «Предпросмотр». Ключ i18n — существующий `node.fields.team`.
- **Вкладка «Конфиг»** ([ConfigTab.tsx](../../web-ui/src/components/node/ConfigTab.tsx)) — строка
  «Команда» показывает **только имя**: убраны `(slug)` и фолбэк на UUID.
- Представление команды = `Team.Name`. Если имя определить не удалось — прочерк «—» (сырой
  идентификатор в UI не выводится).

## 65.3 Источники данных (без новых эндпоинтов)

- **Правка узла:** `useNodeTeam(id)` — резолвер §58 (`GET /api/nodes/{id}/team` → `team_name`).
  Ключ `["node-team", id]` уже закеширован хуком `useEnsureNodeTeam`, который страница узла и форма
  вызывают для авто-переключения команды, — второго запроса нет.
- **Создание узла:** имя текущей команды сессии из членств (`useMyTeams()`,
  `items.find(id === current_team_id).name`) — узел будет создан именно в ней.
- **Вкладка «Конфиг»:** имя по членствам (`useMyTeams`) с фолбэком на `useNodeTeam(node.id)`
  (уже закеширован страницей узла).

## 65.4 Вне scope

- Смена команды с формы (перенос узла — отдельная кнопка «Перенести», §59/§60/§61).
- Показ slug/UUID команды в UI узла (доступны в Settings → Teams).
